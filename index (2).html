How to get a YouTube API key (free)

    

  1. Open console.cloud.google.com and sign in.
    2. 

  2. Create a new project (any name).
    3. 

  3. Go to APIs & Services, then Library. Search "YouTube Data API v3" and click Enable.
    4. 

  4. Go to Credentials, then Create credentials, then API key.
    5. 

  5. Click the key, under Website restrictions add your GitHub Pages address (https://yourname.github.io/*), and under API restrictions choose YouTube Data API v3. This stops others from using your key.
    6. 

  6. Paste the key in Settings above and save.
    7.
